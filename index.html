電位的四種解法

第 2 章教了怎麼用電荷分布求電位。原則上，下面這一個積分就能算出任何靜電位：

\[ V(\mathbf r) = \frac{1}{4\pi\epsilon_0}\int \frac{\rho(\mathbf r')}{|\mathbf r - \mathbf r'|}\,d\tau' \]

第 3 章要回答的是：這個積分算不出來的時候，怎麼辦？這一章給了四種工具，每一種都會用在之後的章節。

原書 p.113，Eq. 3.2
2
開場

為什麼不直接積分

  • 算不出來：除了最簡單的電荷分布，這類積分通常沒辦法解析計算。
  • 連 ρ 都不知道：有導體時，電荷會自己移動。我們能控制的只有每個導體的總電荷或電位，不知道電荷怎麼分布。

所以改用微分形式：解泊松方程，再配上適當的邊界條件。兩者合起來和積分公式等價。

\[ \nabla^2 V = -\frac{1}{\epsilon_0}\rho \]

拉普拉斯方程

很多時候我們只關心沒有電荷的區域（電荷可以在區域外面）。這時泊松方程就化成拉普拉斯方程（Laplace's equation）：

\[ \nabla^2 V = 0 \qquad\Longleftrightarrow\qquad \frac{\partial^2 V}{\partial x^2} + \frac{\partial^2 V}{\partial y^2} + \frac{\partial^2 V}{\partial z^2} = 0 \]

它的解叫做調和函數（harmonic functions）。作者說，靜電學「幾乎可以說就是在研究拉普拉斯方程」；這個方程也出現在重力、熱傳導、肥皂泡等地方。

補充\(\nabla^2 V\) 可以理解成「V 在某點的值和它周圍平均值的差」。\(\nabla^2 V = 0\) 就是「每一點都等於周圍的平均」，下一張會看到這正是它最重要的性質。

原書 p.113–114，Eq. 3.3–3.5
5
Part 1 · §3.1.2–3.1.3

一維與二維：直線，而且是平均

一維：\(d^2V/dx^2 = 0\)，通解是直線 \(V = mx + b\)。兩個常數由兩個邊界條件決定。這個簡單的解已經藏著兩個重要性質：

  1. \(V(x) = \tfrac12[V(x+a) + V(x-a)]\)：每一點都是左右兩點的平均。作者稱拉普拉斯方程是一種「取平均的指令」。
  2. 沒有局部極大或極小，極值只出現在端點。

二維：已經是偏微分方程，寫不出封閉的通解，但兩個性質仍成立。圖像是一張繃在高低起伏框上的橡皮膜：膜的高度滿足拉普拉斯方程，乒乓球放上去只會滾下去，找不到可以停留的凹處。

「二階導數為零，所以沒有極值」不算證明：\(x^4\) 在 \(x = 0\) 的二階導數也是零，卻是極小值。
原書 p.114–116，Eq. 3.6
中點 x = 3 的值永遠等於 x = 3 ± a 兩點的平均

Part 1 · §3.1.4

三維：平均值性質

三維沒有顯式解，也沒有直觀比喻，但兩個性質依然成立：

\[ V(\mathbf r) = \frac{1}{4\pi R^2}\oint_{\text{sphere}} V\,da \]

由此，V 在無電荷區域內沒有局部極值：若某點是極大，周圍小球面上的值都比它小，平均也會比它小，矛盾。

證明：先看球外一個點電荷 q，把它放在 z 軸上距球心 z 處，對球面取平均：

\[ V_{\text{ave}} = \frac{q}{4\pi\epsilon_0}\frac{1}{2zR}\Big[(z+R)-(z-R)\Big] = \frac{1}{4\pi\epsilon_0}\frac{q}{z} \]

恰好是 q 在球心的電位。由疊加原理，球外任意電荷都成立。

補充恩紹定理（Earnshaw）：帶電粒子不可能只靠靜電力穩定平衡，因為電位沒有可以停留的「坑」（Prob. 3.2）。

鬆弛法

平均值性質提示了一種數值解法，叫鬆弛法（method of relaxation），很多電腦解拉普拉斯方程的程式就是這樣做的：

  1. 邊界上的 V 照題目給定，內部格點先隨便猜一個值。
  2. 第一輪：把每個內部格點換成它四個鄰居的平均。
  3. 用新的值再做一輪，反覆進行。

幾輪之後數值就不太變了，這就是滿足邊界條件的數值解。

補充圖中就是這個流程。不管一開始猜什麼，最後都收斂到同一個答案——這也預告了下面的唯一性定理。

邊界條件要給多少

拉普拉斯方程本身決定不了 V，還要配邊界條件。問題是：要給到多少才夠，又不會多到互相矛盾？

一維的答案很清楚：通解有兩個常數，所以要兩個條件。可以兩端各給值，也可以一端給值和導數；但只給一端的值（或只給一端的導數）不夠，兩端都只給導數則不是多餘就是矛盾。

二維、三維就不明顯了。例如：繃緊的膜的形狀，是否由框唯一決定？還是會像罐頭蓋那樣，在兩種穩定形狀之間「啪」地切換？

直覺是對的：只要給定邊界上的 V，解就唯一。證明這類事情的工具叫唯一性定理。

一端給 V 和 dV/dx✓ 足夠

第一唯一性定理

在體積 𝒱 內，拉普拉斯方程的解只要在邊界面 𝒮 上的值都給定，就是唯一的。

邊界上的 V 不必是常數，可以逐點變化；區域內可以有「島」，外邊界也可以在無限遠。

證明（四步）：

  1. 假設有兩個解 \(V_1, V_2\)，令 \(V_3 = V_1 - V_2\)。
  2. 由線性，\(\nabla^2 V_3 = 0\)。
  3. 邊界上 \(V_1 = V_2\)，所以 \(V_3 = 0\)。
  4. \(V_3\) 沒有局部極值，極大、極小都在邊界上，都是 0，所以 \(V_3 \equiv 0\)。

推論：區域內有電荷時，只要 ρ 和邊界上的 V 都給定，解同樣唯一（相減後 ρ 抵消）。

註：這裡只證明唯一性，沒有證明解一定存在。原書 p.119–120

想像力的執照

作者這樣形容唯一性定理：

“The uniqueness theorem is a license to your imagination.”
唯一性定理是給你想像力的執照。（p.120）

不管你是怎麼得到一個解的——猜的、湊的、從別的問題借來的——只要它 (a) 滿足拉普拉斯方程，(b) 在邊界上的值正確，它就是答案。後面的鏡像法和分離變數法，都是在用這張執照。

順帶一例（Ex. 3.1）：被導體完全包圍、裡面沒有電荷的空腔。空腔壁是等位面 \(V_0\)，猜「腔內處處 \(V = V_0\)」——它滿足方程也滿足邊界，所以就是唯一解，腔內電場為零。

第二唯一性定理

實驗室裡常常不知道導體的電位，只知道在每個導體上放了多少電荷。電荷放上去後會自己分布，有沒有可能用好幾種方式分布、產生不同的電場？

被導體包圍的區域內，若 ρ 給定，且每個導體的總電荷給定，則電場 \(\mathbf E\) 唯一。

證明關鍵：令 \(\mathbf E_3 = \mathbf E_1 - \mathbf E_2\)，則 \(\nabla\cdot\mathbf E_3 = 0\)，且每個邊界面上 \(\oint \mathbf E_3\cdot d\mathbf a = 0\)。每個導體是等位體，所以 \(V_3\) 在每個導體表面是常數。再用

\[ \nabla\cdot(V_3\mathbf E_3) = -(E_3)^2 \;\Longrightarrow\; \int_{\mathcal V}(E_3)^2\,d\tau = 0 \]

被積函數不會是負的，所以 \(\mathbf E_3 = 0\)。作者坦言這個證明不容易。

Purcell 的例子

如果你覺得第二唯一性定理「顯然」，看這個例子：

  1. 四個導體分別帶 ±Q，正電荷靠近負電荷，看起來很穩定。
  2. 用細線把它們兩兩連起來。直覺會說：正負已經彼此靠近了，應該什麼都不會發生。
  3. 但連起來後只剩兩個導體，各自的總電荷都是 0。「到處沒有電荷、電場為零」符合條件。
  4. 由第二唯一性定理，這就是唯一的解：電荷會沿細線流過去、全部中和。

教訓：決定結果的是全局條件（每個導體的總電荷），不是「正負靠近就穩定」的局部直覺。

經典問題

點電荷 \(+q\) 放在一塊無限大、接地的導體平面上方，距離 d。平面上方的電位是多少？

它不只是 \(q/4\pi\epsilon_0|\mathbf r - \mathbf r'|\)：q 會在導體表面感應出負電荷，而感應電荷有多少、怎麼分布，我們都不知道。

改寫成邊界值問題：在 \(z > 0\) 解泊松方程，區域內只有 \((0,0,d)\) 的點電荷，條件是

  1. \(z = 0\) 時 \(V = 0\)（平面接地）
  2. 離電荷很遠時 \(V \to 0\)

唯一性定理（的推論）保證只有一個函數符合這些條件。只要猜得到，就是答案。

鏡像電荷

技巧：忘掉原問題，改看一個完全不同的配置——\(+q\) 在 \((0,0,d)\)，\(-q\) 在 \((0,0,-d)\)，沒有導體。它的電位很好寫：

\[ V(x,y,z) = \frac{1}{4\pi\epsilon_0}\left[\frac{q}{\sqrt{x^2+y^2+(z-d)^2}} - \frac{q}{\sqrt{x^2+y^2+(z+d)^2}}\right] \]
  • \(z = 0\) 時，到兩個電荷的距離相等 → \(V = 0\)
  • 遠處兩項都趨於 0 → \(V \to 0\)
  • \(z > 0\) 裡只有 \(+q\)，和原問題相同

條件全部符合，所以在 \(z \ge 0\)，這就是原問題的電位。下半空間完全不同，但我們不在乎。作者強調：沒有唯一性定理，沒人會相信這個從不同電荷分布得到的解。

感應面電荷

知道電位後，用第 2 章的 \(\sigma = -\epsilon_0\,\partial V/\partial n\)（這裡法線就是 z 方向）就能求出平面上的感應電荷：

\[ \sigma(x,y) = -\epsilon_0\frac{\partial V}{\partial z}\bigg|_{z=0} = \frac{-qd}{2\pi(x^2+y^2+d^2)^{3/2}} \]

它是負的，在 q 正下方最多。改用極座標積分，總感應電荷是

\[ Q = \int_0^{2\pi}\!\!\int_0^{\infty}\frac{-qd}{2\pi(r^2+d^2)^{3/2}}\,r\,dr\,d\phi = -q \]

作者說：事後想想，這「必須」如此。

力可以照搬，能量不行

力：q 附近的電位和鏡像問題相同，所以電場、力也相同：

\[ \mathbf F = -\frac{1}{4\pi\epsilon_0}\frac{q^2}{(2d)^2}\,\hat{\mathbf z} \]

能量：作者警告，別以為兩個問題的所有東西都一樣。原問題的能量只有兩電荷配置的一半：

\[ W = -\frac{1}{4\pi\epsilon_0}\frac{q^2}{4d} \quad\text{（而非 } -\tfrac{1}{4\pi\epsilon_0}\tfrac{q^2}{2d}\text{）} \]
  • 場能量看法：\(W = \frac{\epsilon_0}{2}\int E^2 d\tau\)。鏡像問題上下對稱各佔一半；原問題只有上半空間有電場。
  • 做功看法：把 q 從遠處推進來只對 q 做功；感應電荷在零電位的導體上移動，不花力氣。

推廣與限制

接地平面附近的任何靜止電荷分布，都可以放一個反號的「鏡像」來處理——這就是鏡像法名稱的由來。

順帶一例（Ex. 3.2）：點電荷 q 在半徑 R 的接地導體球外、距球心 a。鏡像放在球內：

\[ q' = -\frac{R}{a}\,q, \qquad b = \frac{R^2}{a} \]
規則：鏡像電荷不能放在求解區域內，否則等於改變了區域內的 ρ，解的就是錯的泊松方程。

限制：作者說鏡像法簡單得令人愉快——在它行得通的時候。大多數形狀想不出合適的鏡像，這時要改用下一節的分離變數法。

乘積解

這一節直接解拉普拉斯方程。作者稱分離變數法是物理學家解偏微分方程最愛的工具；適用於區域邊界上的 V（或 σ）已給定、要求內部電位的情況。

以原書的「無限長槽」為例（Ex. 3.3）：兩塊接地平板在 \(y = 0\) 與 \(y = a\)，左端 \(x = 0\) 維持在 \(V_0(y)\)。邊界條件：

  • \(y = 0\)、\(y = a\) 時 \(V = 0\)
  • \(x = 0\) 時 \(V = V_0(y)\)；\(x \to \infty\) 時 \(V \to 0\)（物理上必須如此）

第一步：找乘積形式的解 \(V(x,y) = X(x)\,Y(y)\)。這看似荒謬——絕大多數解都不是乘積，例如 \(5x + 6y\)。但這些特殊解拼起來就能構成通解。

分離與選常數

代入後除以 V，得到 \(f(x) + g(y) = 0\) 的形式。唯一可能是兩項都是常數：若 f 會隨 x 變，固定 y、只動 x，總和就會改變。作者提醒：這個論證簡單卻容易滑過，整個方法都建立在它上面。

選常數的正負：一般要考慮所有可能。這題需要

  • x 方向是指數：才能在 \(x \to \infty\) 時趨於 0
  • y 方向是正弦：才能在 \(y = 0\) 與 \(y = a\) 都是 0

套用三個「等於零」的邊界條件後，得到一族離散的解，\(k = n\pi/a\)。\(n = 0\) 會讓電位處處為 0，不能用。

有些問題也必須把常數為零的情況納入（原書 p.131 註 9）。

Part 3 · §3.3.1

線性疊加

到這裡，除非 \(V_0(y)\) 剛好是某個 \(\sin(n\pi y/a)\)，否則沒有任何一個分離解能配上 \(x = 0\) 的邊界。

拯救方法的關鍵：分離解有無限多個（每個 n 一個），而拉普拉斯方程是線性的——任意線性組合仍是解。所以把它們疊加起來：

\[ V(x,y) = \sum_{n=1}^{\infty} C_n\, e^{-n\pi x/a}\sin(n\pi y/a) \]

它仍滿足三個邊界條件。最後一個條件變成

\[ V(0,y) = \sum_{n=1}^{\infty} C_n\sin(n\pi y/a) = V_0(y) \]

這是 Fourier 正弦級數。Dirichlet 定理保證幾乎任何 \(V_0(y)\)（即使有有限個不連續點）都能這樣展開。

Fourier 技巧

係數 \(C_n\) 埋在無窮級數裡，怎麼求？作者說這招漂亮到值得取名字，叫 Fourier 技巧：兩邊同乘 \(\sin(n'\pi y/a)\)，從 0 積分到 a。由正交性

\[ \int_0^a \sin(n\pi y/a)\sin(n'\pi y/a)\,dy = \begin{cases}0 & n'\neq n\\ a/2 & n'=n\end{cases} \]

級數中只剩 \(n = n'\) 那一項，於是

\[ C_n = \frac{2}{a}\int_0^a V_0(y)\sin(n\pi y/a)\,dy \]

順帶一例（Ex. 3.3）：\(V_0\) 為常數時，只有奇數項存活，\(C_n = 4V_0/n\pi\)：

\[ V(x,y) = \frac{4V_0}{\pi}\sum_{n=1,3,5,\ldots}\frac{1}{n}e^{-n\pi x/a}\sin(n\pi y/a) \]

Part 3 · §3.3.1

完備性與正交性

這個方法的成功，取決於分離解的兩個性質：

  • 完備性（completeness）：任何函數都能寫成它們的線性組合，\(f(y) = \sum C_n f_n(y)\)。它保證係數存在。證明完備性非常困難，作者說物理學家通常直接假設它成立。
  • 正交性（orthogonality）：任兩個不同成員的乘積積分為 0，\(\int_0^a f_n f_{n'}\,dy = 0\)。它讓我們算得出係數。通常容易證明。

補充線性代數的類比：把函數看成無限維空間的向量、積分看成內積。正交的函數族就像互相垂直的座標軸，Fourier 技巧就是把向量投影到第 n 個軸上；完備性則是說這組軸夠張成整個空間。

有限區域與三維

同一套步驟可以推廣，但有幾個地方要小心：

  • 區域有限時，不能丟掉增長的 \(e^{kx}\)。例如兩端都封住的矩形管（Ex. 3.4），改用對稱性 \(V(-x,y) = V(x,y)\) 得到 cosh 形式。

球座標

邊界是平面時用直角座標；遇到圓形物體，球座標比較自然。作者假設方位角對稱（V 與 φ 無關），拉普拉斯方程化簡成

\[ \frac{\partial}{\partial r}\left(r^2\frac{\partial V}{\partial r}\right) + \frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial V}{\partial\theta}\right) = 0 \]

設 \(V = R(r)\Theta(\theta)\)。分離常數刻意寫成 \(l(l+1)\)，下一張會看到為什麼方便。

V 依賴 φ 的一般情況，作者留給研究所教科書（例如 Jackson 第 3 章）。

勒讓德多項式

角度方程的解是以 \(\cos\theta\) 為變數的勒讓德多項式（Legendre polynomials），\(\Theta = P_l(\cos\theta)\)，可用 Rodrigues 公式定義：

\[ P_l(x) \equiv \frac{1}{2^l\,l!}\left(\frac{d}{dx}\right)^l (x^2-1)^l \]
  • \(P_l\) 是 l 次多項式；l 為偶數只含偶次方，奇數只含奇次方
  • 前面的係數是為了讓 \(P_l(1) = 1\)
  • 在 \(0 \le \theta \le \pi\) 上完備且正交：
\[ \int_0^{\pi}P_l(\cos\theta)P_{l'}(\cos\theta)\sin\theta\,d\theta = \begin{cases}0 & l'\neq l\\ \dfrac{2}{2l+1} & l'=l\end{cases} \]

角度方程的另一個解在 θ = 0 或 π 會發散，物理上不可接受，所以捨棄。

Part 4 · §3.4.1

總電荷為零時呢？

離一個局部電荷分布很遠時，它看起來像點電荷，\(V \approx \frac{1}{4\pi\epsilon_0}\frac{Q}{r}\)。但如果總電荷 \(Q = 0\)，說「電位約等於零」雖然沒錯，卻沒什麼資訊。

順帶一例（Ex. 3.10）：物理電偶極，±q 相距 d。用餘弦定理寫出到兩電荷的距離，在 \(r \gg d\) 時做二項式展開：

\[ V(\mathbf r) \approx \frac{1}{4\pi\epsilon_0}\frac{qd\cos\theta}{r^2} \]

偶極的電位隨 \(1/r^2\) 衰減，比點電荷快。

多極的階層

把兩個相反的偶極擺在一起成為四極，電位隨 \(1/r^3\)；兩個背對背的四極成為八極，電位隨 \(1/r^4\)……

名稱電位電場
單極（點電荷）\(\propto 1/r\)\(\propto 1/r^2\)
偶極\(\propto 1/r^2\)\(\propto 1/r^3\)
四極\(\propto 1/r^3\)\(\propto 1/r^4\)
八極\(\propto 1/r^4\)\(\propto 1/r^5\)

電場比對應的電位多一個 \(1/r\)，因為取梯度又多除了一次 r。

補充離得越遠，越高階的貢獻越早消失。遠處看到的，永遠是「最低階的非零那一項」。

Part 4 · §3.4.1

一般的多極展開

對任意局部電荷分布，用餘弦定理寫出 \(|\mathbf r - \mathbf r'|\)（α 是 \(\mathbf r\) 與 \(\mathbf r'\) 的夾角），在遠處做二項式展開。依 \(r'/r\) 的冪次整理後，係數「出乎意料地」正好是勒讓德多項式：

\[ \frac{1}{|\mathbf r - \mathbf r'|} = \frac{1}{r}\sum_{n=0}^{\infty}\left(\frac{r'}{r}\right)^n P_n(\cos\alpha) \]

代回積分公式，得到多極展開：

\[ V(\mathbf r) = \frac{1}{4\pi\epsilon_0}\sum_{n=0}^{\infty}\frac{1}{r^{n+1}}\int (r')^n P_n(\cos\alpha)\,\rho(\mathbf r')\,d\tau' \]

這個式子是精確的，但主要用作近似：最低的非零項就是遠處的電位，後面的項用來提高精度。注意積分依賴場點的方向（因為 α）。

上面這個展開也是勒讓德多項式的第二種定義，叫生成函數。

偶極矩與原點

展開的前兩項：單極 \(V_{\text{mon}} = \frac{1}{4\pi\epsilon_0}\frac{Q}{r}\)，以及偶極

\[ V_{\text{dip}} = \frac{1}{4\pi\epsilon_0}\frac{\mathbf p\cdot\hat{\mathbf r}}{r^2}, \qquad \mathbf p \equiv \int \mathbf r'\rho(\mathbf r')\,d\tau' \]

\(\mathbf p\) 叫偶極矩。點電荷時 \(\mathbf p = \sum q_i\mathbf r_i'\)；物理偶極 \(\mathbf p = q\mathbf d\)（\(\mathbf d\) 由負指向正）。純偶極是取 \(d \to 0\)、\(q \to \infty\) 而 \(qd\) 固定的極限。

原點的影響：原點移動 \(\mathbf a\) 後，

\[ \bar{\mathbf p} = \mathbf p - Q\mathbf a \]

所以只有總電荷為零時，偶極矩才與原點無關。問總電荷不為零的配置的偶極矩，正確的回答是「相對於哪個原點？」

偶極的電場

把純偶極放在原點、指向 z，電位是 \(V = \frac{p\cos\theta}{4\pi\epsilon_0 r^2}\)。取負梯度：

\[ \mathbf E_{\text{dip}}(r,\theta) = \frac{p}{4\pi\epsilon_0 r^3}\left(2\cos\theta\,\hat{\mathbf r} + \sin\theta\,\hat{\boldsymbol\theta}\right) \]

座標無關的寫法是 \(\mathbf E_{\text{dip}} = \frac{1}{4\pi\epsilon_0}\frac{1}{r^3}\left[3(\mathbf p\cdot\hat{\mathbf r})\hat{\mathbf r} - \mathbf p\right]\)（Prob. 3.38）。

偶極電場隨 \(1/r^3\) 衰減。純偶極與物理偶極的電力線，遮住中心時很像，靠近中心時完全不同；只有 \(r \gg d\) 時，上式才是物理偶極的好近似。

結尾

遇到題目怎麼選

  1. 只想知道遠處的行為？→ 多極展開，取最低的非零項。
  2. 有導體，感應電荷未知？直接積分行不通，改解邊界值問題：
    • 導體是平面或球、源是點電荷 → 先試鏡像法
    • 邊界是完整的座標面 → 分離變數法
    • 只知道導體總電荷 → 第二唯一性定理保證仍有唯一電場
  3. 電荷分布全部已知？對稱性高就用高斯定律；球面上有角度依賴的面電荷，分離變數法常比積分容易。
  4. 只想知道定性行為？→ 平均值性質：無電荷區域內沒有極值。

結尾

三件事帶走

  1. 唯一性定理負責認證：方程和邊界條件都對，就是唯一的答案。
  2. 各方法負責猜解：鏡像法用假想電荷，分離變數法用級數疊加；多極展開則從積分公式直接展開成近似。
  3. 一切建立在線性上：電位可以疊加，所以這些方法才成立。

補充勒讓德多項式同時出現在球座標的分離變數法和多極展開中，因為 \(1/|\mathbf r - \mathbf r'|\) 本身就是拉普拉斯方程的解。
