# 電位的四種解法——Griffiths 第 3 章導讀

給正在用 Griffiths《Introduction to Electrodynamics》（第 4 版）修電磁學的大學生的捲動式導讀網頁，涵蓋第 3 章 Potentials 的四節：

- §3.1 拉普拉斯方程：平均值性質、鬆弛法、兩個唯一性定理
- §3.2 鏡像法：接地平面、感應面電荷、能量陷阱、導體球
- §3.3 分離變數法：Fourier 技巧、完備性與正交性、勒讓德多項式
- §3.4 多極展開：多極階層、偶極矩與原點、偶極電場

共 33 張投影片、11 個可操作的互動圖。寬螢幕上，文字在左側捲動、對應的圖固定在右側切換；手機上圖文依序排列。每張都標有原書頁碼與公式編號，方便對照課本；每節最後附「課本練習」題號。
